# Tic-Tac-Toe (Java & Python)

A simple two-player Tic-Tac-Toe game I made in both Java and Python while learning programming. Both versions run in the console and let two players take turns placing X's and O's.

## Features
- Two-player gameplay
- Checks for wins across rows, columns, and diagonals
- Detects ties
- Prevents moves outside the board or in occupied spaces
- Displays the board after each valid move
- Python version includes an option to play again

## Concepts Used
- Java and Python
- Arrays and lists
- Loops and conditional statements
- Functions and methods
- Game logic and input validation
- Object-oriented programming (Java version)

## How to Run
**Java:** Open `TicTacToe.java` in a Java IDE and run the program. Enter a row and column from 0–2 to make a move.

**Python:** Run the Python file and enter a number from 1–9 to choose a spot on the board.
